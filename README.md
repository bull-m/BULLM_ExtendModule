# 控制模块控制库

> 本库为配合牛明工作室的一些I2C扩展板而设计的库。

**目前支持了下面这些扩展模块**

# 电机驱动扩展模块

8路 [https://bullm.cn/extend-motor](https://bullm.cn/extend-motor)

8路大功率 [https://bullm.cn/extend-motor-power-8](https://bullm.cn/extend-motor-power-8)

4路大功率  [https://bullm.cn/extend-motor-power-4](https://bullm.cn/extend-motor-power-4)

# MOS驱动扩展模块

16路 [https://bullm.cn/extend-mos-16](https://bullm.cn/extend-mos-16)

8路 [https://bullm.cn/extend-mos-8](https://bullm.cn/extend-mos-8)

# 继电器扩展模块

8路 [https://bullm.cn/extend-relay-8](https://bullm.cn/extend-relay-8)

4路 [https://bullm.cn/extend-relay-4](https://bullm.cn/extend-relay-4)

# I2C复用模块

4路 [https://bullm.cn/extend-i2c-4](https://bullm.cn/extend-i2c-4)
